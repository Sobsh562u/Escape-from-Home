存档与账号

一局打到一半，换台设备也能接着打。存档包在网页版、桌面版、Python 版之间是通的。

怎么导出

  • 网页版：点「导出存档包」，浏览器会问你存到哪，自己选目录
  • 安卓包：点同一个按钮，文件直接落到手机的「下载」目录，会有提示
  • 桌面版 / Python 版：输入 导出，会生成文件

文件格式不一样，但内容能互通

网页版和 Python 版导出的是 zip，里面装着 存档.json 和一份可读的说明文本；C 版导出的是纯 json。想把网页版的存档拿去桌面版续玩，先把 zip 解压，取出里面的 存档.json 再导入。

给存档加密码

网页版导出时可以填密码。加了密码的存档按 AES-GCM 加密，别人拿到文件也打不开，只能在网页版里输入密码解开。密码丢了这份存档就解不开了，没有找回的办法。

存档里到底记了什么

游戏名、版本号、难度、第几天、血条与血条上限、存档时间，还有这几天经历过的事。也就是说导入之后，你的进度和日志都能对得上。

账号和玩家 ID

想上在线总榜要注册：填一个名字和密码，服务器会给你一个 6 位玩家 ID。名字是榜上显示的名字，密码只存哈希，服务器那边看不到明文。

注册后这局结束自动提交成绩。榜上每个名字只留最好的一条记录，刷更低的分不会覆盖。

什么情况下不上榜

  • 没登录：成绩只在本地，不上传
  • 用过作者模式：按规矩不上榜
  • 断网：提交会失败，但游戏本身照常能玩
