# 逃家游戏（Escape from Home）

**[▶ 在线试玩](https://Sobsh562u.github.io/Escape-from-Home/)** —— 手机电脑打开就能玩，不用下载。

你被关在家里天天考试，唯一的盼头是撑到 18 岁、名下有套房，然后逃出去。

一个纯文字小游戏。**核心是桌面版**——一个 C 写的小程序，五难度合一，支持存档导入导出；另外提供 Python 源码和网页试玩版。

## 快速开始

三条命令，按你手头的环境选一条：

```bash
# Windows：双击 逃家游戏.exe，或在命令行
逃家游戏.exe

# Linux
chmod +x 逃家游戏_linux
./逃家游戏_linux

# 有 Python 3 就行
python3 逃家游戏_原始版.py
```

启动后选难度（1-4），然后每回合按回车考试。想存进度：输入 `导出`；想续上：输入 `导入`。

**系统要求**：Windows 7 及以上 / 常见 Linux 发行版；不需要安装 Python 或任何运行库（C 版静态编译）。

## 下载 / 打开方式

按你的设备选一个：

- **手机 / 不想装东西**：[网页在线版](https://Sobsh562u.github.io/Escape-from-Home/) —— 打开就能玩，存档在浏览器里
- **Windows（主力）**：`逃家游戏.exe` —— 仓库里直接点，或去 [Releases](https://github.com/Sobsh562u/Escape-from-Home/releases) 下载。双击运行，四个难度都在里面，不用装 Python
- **Linux（主力）**：`逃家游戏_linux` —— 静态链接，`chmod +x 逃家游戏_linux` 后运行，不挑发行版
- **有 Python 3**：`逃家游戏_原始版.py` 等五个脚本，`python3` 直接跑（跑路版是 `逃家游戏_跑路版.py`）
- **想看源码**：`逃家游戏_C版.c` —— 桌面版本体，单文件，只依赖 libc

Windows 首次运行如果弹「Windows 已保护你的电脑」，是因为这个程序没有花钱买代码签名证书——点 **更多信息 → 仍要运行** 即可。

## C 版怎么用（桌面版，推荐）

一个程序搞定四个难度，启动后选 1-4：

```
逃家游戏.exe            Windows 直接双击
./逃家游戏_linux        Linux：chmod +x 后运行
```

选难度也可以直接用命令行参数跳过菜单：

```
./逃家游戏_linux -m orig     原始版
./逃家游戏_linux -m revert   反转版
./逃家游戏_linux -m hard     困难版
./逃家游戏_linux -m limit    极限版
```

自己编译（只要 gcc）：

Linux 上直接编：

```
gcc 逃家游戏_C版.c -O2 \
    -o 逃家游戏_linux
```

在 Linux 上编 Windows 版（需要 mingw-w64）：

```
x86_64-w64-mingw32-gcc 逃家游戏_C版.c -O2 \
    -o 逃家游戏.exe
```

本机没装 mingw 时，也可以用 `pip3 install ziglang` 之后：

```
zig cc -target x86_64-windows-gnu -O2 \
    逃家游戏_C版.c -o 逃家游戏.exe
```

C 版支持的全部操作：**回车考试 / `跑` 逃跑 / `110` 报警 / `12345678` 作者模式跳天数 / `导出` 存档 / `导入` 存档**。

## 存档包：桌面版、Python 版、网页版互通

一局打到一半想换设备接着玩，就导出存档：

- **网页版**：点「导出存档」，得到一个 zip
- **Python 版 / C 版**：输入 `导出`，得到一个 json（C 版）或 zip（Python 版）

接着玩：

- 网页版点「导入存档」，选那个文件就行
- 桌面版输入 `导入`，把文件路径填进去（C 版要的是 json，网页版的 zip 先解压出里面的 `存档.json`）

存档里记着：游戏名、版本号、难度、第几天、血条、血条上限、存档时间、这几天经历过什么。网页版还能给存档加密码（加密包只能在网页版里解开）。

## Python 版怎么跑

```
python3 逃家游戏_原始版.py
```

Windows 上双击 `.py` 文件也行。不需要装任何第三方库。

可选的版本：

- `逃家游戏_原始版.py`　撑 5 天，最经典的平衡

- `逃家游戏_极限版.py`　扣血 = 100 - 分数，考 0 分皮带打死

## 通用操作

每一回合可以输入：

- **直接回车**（或随便打字）：妈妈发卷子，考试一次
- **跑**：尝试逃跑（后果各版本不同）
- **110**：报警，触发隐藏结局
- **12345678**：作者模式，跳天数（可以填负数，有彩蛋）

## 原始版玩法

- 血条 100，被打就掉血，血条归零就死
- 每天考一次，分数 0-100：
  - 考 0 分：妈妈暴怒，扣 40 血（最狠）
  - 60 分以下：考砸，扣 15 血
  - 60 分及以上：考得好，加 10 血（封顶 100）
- 撑过 5 天通关：18 岁生日，打开写着自己名字的房子，逃出这个家
- 输入 110：一段报警对话，警察把妈妈带走，隐藏结局「正义の报警」
- 作者模式输入负数天数：穿越到妈妈还没出生的年代，触发祖父悖论

## 反转版玩法

规则全部反过来，考得好反而是坏事：

- 考砸（60 分以下）：妈妈反而放心，加血
- 考好（60 分及以上）：妈妈怕你太优秀，扣血
- 要撑到 6570 天（18 岁）才到高考，中间每天都要考
- 最后一天高考，0-750 分，分数越高结局越惨：
  - 700 分以上：妈妈认定你作弊，被打死
  - 400-699 分：考上本科却被逼复读、关在家里，失去自由
  - 200-399 分：大专，妈妈懒得管，搬出去住，自由
  - 200 分以下：妈妈气晕没人管你，反而自由
- 输入 110：警察抓的是你自己
- 输入 跑：年龄越小越容易跑掉，快成年了反而在门口被抓回

## 困难版玩法

血条只有 50，妈妈更暴躁，要撑 10 天才能到 18 岁。

- 初始血条 50，上限 50，被打就掉血
- 每天考一次，分数 0-100：
  - 考 0 分：妈妈让你跪墙角，扣 25 血（一半血没了）
  - 60 分以下：又不及格，扣 15 血
  - 60-89 分：勉强及格，加 5 血
  - 90 分以上：加 8 血（血条封顶 50）
- 输入 跑：想跑也得付代价
  - 20% 概率被妈妈当场抓回，扣 10 血
  - 其余情况跑出去又冷又饿，扣 5 血
  - 跑完这回合照样算一天
- 输入 110：警察不信你，当成恶作剧挂了电话，结局直接结束，没人来救你
- 输入 12345678：作者模式，可以跳到指定天数
- 撑满 10 天、血条不为 0：困难模式通关

## 极限版玩法

最狠的一版，规则只有一句：**扣血 = 100 - 分数**。

- 血条 100，考几分就扣几分的血（考 100 分不扣血，考 10 分扣 90 血）
- **考 0 分不是扣血，是爸爸解下皮带打死你**：多少血都没用，游戏强制结束
- 扣血对照：0 分 → 皮带打死，10 分 → 扣 90，20 分 → 扣 80，30 分 → 扣 70，40 分 → 扣 60，50 分 → 扣 50，60 分 → 扣 40，70 分 → 扣 30，80 分 → 扣 20，90 分 → 扣 10，100 分 → 不扣
- 撑过 5 天：18 岁，逃出这个家
- 输入 110：接电话的是爸爸——「还敢报警？回家再说」，直接被逮住
- 输入 12345678：作者模式，可以跳天数

## 网页版说明

网页版在 `index.html` 里，单文件、无依赖，直接部署在 GitHub Pages：

- **五个版本可切换**（原始 / 反转 / 困难 / 极限 / 跑路），和桌面版规则完全一致
- 血条、天数实时显示，血条低于三成会变红
- 每考完一场有 45% 概率蹦出随机事件（妈妈出门、邻居送饼干、半夜停电……）
- **自动存档**：存在浏览器本地，关掉网页也还在
- **存档包导出 / 导入**：导出是 zip，里面 `存档.json` 记录难度、天数、血条和全部经历，`存档说明.txt` 是给人看的
- **加密可选**：导出时设个密码，存档包就是 AES-GCM 密文，别人改一个字节都打不开
- **结局图鉴**：20 个结局，打出来一个点亮一个，没打出来的显示「？？？」，存在浏览器里，换难度不丢
- **最佳记录**：每个难度的最快通关天数和剩余血条都记着，破记录会更新

## 常见问题

**Q：双击 exe 弹「Windows 已保护你的电脑」？**
没买代码签名证书（几千块一年），点「更多信息 → 仍要运行」即可。源码就在仓库里，可以自己编译。

**Q：能读到别人的存档吗，会不会被偷？**
存档只在你本机生成，游戏不联网、不上传任何数据。网页版的存档存在浏览器本地（`localStorage`）。

**Q：网页版的存档能给桌面版用吗？**
能。网页版导出的是 zip，Python 版直接读；C 版先解压出 `存档.json` 再导入。反过来也成立。

**Q：存档被改过怎么办？**
导出时设个密码，存档就是 AES-GCM 密文，改一个字节就解不开。不设密码的话，本地程序无法验证真伪——这是没有服务器的必然结果。

**Q：手机上能玩桌面版吗？**
不能，手机上只有网页版。安卓/iOS 都通过 [在线试玩](https://Sobsh562u.github.io/Escape-from-Home/) 打开。

**Q：会一直更新吗？**
会，版本走到 2.x 以后还会继续加东西。看 [CHANGELOG.md](CHANGELOG.md) 和 Releases。

## 版本对比

一句话版：原始版考平衡，反转版规则全反，困难版血少且跑有代价，极限版考砸就要命，跑路版要靠攒钱。

**跑路版（攒钱版）** —— 血条 100 / 100，不限天数。60–89 分给 1–3 块、90 分以上给 3–5 块；60 分以下不给钱还扣血。攒到 60 块（车票 50 + 买通弟弟 10）就能出门。出门后过三站：幼儿园站被吵（扣 20）、学校站被老师揪住（扣 30）、大学站被你哥按住（扣 40），每站都可以花 10 块打车直接过。过完三站就是终点站。钱够了也可以继续待在家里不走，作者模式还能自己设钱。

- **原始版** —— 血条 100 / 100，撑 5 天。考 0 分 −40，60 分以下 −15，60 分以上 +10。逃跑扣 20 血、不算一天。110 警察会救你。
- **反转版** —— 血条 100 / 100，要撑 6570 天（到 18 岁）才高考。规则全反：考砸加血，考好扣血。3650 天之前跑必成功，越接近 6570 天越容易被抓。110 抓的是你自己。
- **困难版** —— 血条只有 50 / 50，撑 10 天。考 0 分 −25，60 分以下 −15，60–89 +5，90 以上 +8。跑有 20% 概率被抓扣 10，否则扣 5 且算一天。110 没人来救。
- **极限版** —— 血条 100 / 100，撑 5 天。扣血 = 100 − 分数，考 0 分爸爸直接解皮带打死。跑扣 5 血、算一天。110 接电话的是爸爸。

完整数值、隐藏操作和 17 个结局见 [文档-规则与结局.md](文档-规则与结局.md)。

老版本的表格版对比还留在 [CHANGELOG.md](CHANGELOG.md) 的记录里，手机上直接看上面这段更清楚。
