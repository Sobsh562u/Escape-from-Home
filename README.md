# 逃家游戏（Escape from Home）

原名：逃家游戏 Escape from Home (Python)

一个 Python 写的纯文字小游戏。你被关在家里天天考试，唯一的盼头是撑到 18 岁、名下有套房，然后逃出去。

不需要装任何依赖，有 Python 3 就能玩。

## 怎么运行

python3 逃家游戏_原始版.py

Windows 上双击 .py 文件即可，或者命令行输入 python 逃家游戏_原始版.py。

## 通用操作

每一回合你可以输入：

- 直接回车（或随便打字）：妈妈发卷子，考试一次
- 跑：尝试逃跑
- 110：报警（隐藏结局）
- 12345678：作者模式，可以跳天数（部分版本还能改分数）

## 原始版玩法

- 血条 100，被打就掉血，血条归零就死
- 每天考一次，分数 0-100：
  - 考 0 分：妈妈暴怒，扣 40 血（最狠）
  - 60 分以下：考砸，扣 15 血
  - 60 分及以上：考得好，加 10 血（封顶 100）
- 撑过 5 天通关：18 岁生日，打开写着自己名字的房子，逃出这个家
- 输入 110：一段报警对话，警察把妈妈带走，隐藏结局「正义の报警」
- 作者模式输入负数天数有彩蛋：穿越到妈妈还没出生的年代，触发祖父悖论

## 反转版玩法

规则全部反过来，考得好反而是坏事：

- 考砸（60 分以下）：妈妈反而放心，加血
- 考好（60 分及以上）：妈妈怕你太优秀，扣血，最高一次扣 10000
- 需要撑到 6570 天（18 岁）才到高考，中间每天都要考
- 最后一天高考，0-750 分，分数越高结局越惨：
  - 700 分以上：妈妈认定你作弊，被打死
  - 400-699 分：考上本科却被逼复读、关在家里，失去自由
  - 200-399 分：大专，妈妈懒得管，搬出去住，自由
  - 200 分以下：妈妈气晕没人管你，反而自由
- 输入 110：警察抓的是你自己
- 输入 跑：年龄越小越容易跑掉，快成年了反而在门口被抓回

## 困难版玩法

血条只有 50，妈妈更暴躁，要撑 10 天才能到 18 岁。

- 初始血条 50，上限 50，被打就掉血
- 每天考一次，分数 0-100：
  - 考 0 分：妈妈让你跪墙角，扣 25 血（一半血没了）
  - 60 分以下：又不及格，扣 15 血
  - 60-89 分：勉强及格，加 5 血
  - 90 分以上：加 8 血（血条封顶 50）
- 输入 跑：想跑也得付代价
  - 20% 概率被妈妈当场抓回，扣 10 血
  - 其余情况跑出去又冷又饿，扣 5 血
  - 跑完这回合照样算一天
- 输入 110：警察不信你，当成恶作剧挂了电话，结局直接结束，没人来救你
- 输入 12345678：作者模式，可以跳到指定天数
- 撑满 10 天、血条不为 0：困难模式通关

## 三个版本对比

| | 原始版 | 反转版 | 困难版 |
|---|---|---|---|
| 血条 | 100 | 100 | 50 |
| 目标天数 | 5 天 | 6570 天 | 10 天 |
| 考 0 分 | 扣 40 | 加血（反向） | 扣 25 |
| 考好 | 加血 | 扣血（反向） | 加血，但很少 |
| 跑 | 直接结局 | 越小越容易跑掉 | 有代价，扣血 |
| 110 | 警察救你 | 抓你自己 | 没人来救 |
