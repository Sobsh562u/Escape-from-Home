# 逃家游戏 Escape from Home (Python) is now available.(真名)

一个 Python 写的纯文字小游戏。你被关在家里天天考试，唯一的盼头是撑到 18 岁、名下有套房，然后逃出去。

不需要装任何依赖，有 Python 3 就能玩。

## 怎么运行

python3 逃家游戏_原始版.py

Windows 上双击 .py 文件即可，或者命令行输入 python 逃家游戏_原始版.py。

## 通用操作

每一回合你可以输入：

- 直接回车（或随便打字）：妈妈发卷子，考试一次
- 跑：尝试逃跑
- 110：报警（隐藏结局）
- 12345678：作者模式，可以改分数或直接跳到第几天

## 原始版玩法

- 血条 100，被打就掉血，血条归零就死
- 每天考一次，分数 0-100：
  - 考 0 分：妈妈暴怒，扣 40 血（最狠）
  - 60 分以下：考砸，扣 15 血
  - 60 分及以上：考得好，加 10 血（封顶 100）
- 撑过 5 天通关：18 岁生日，打开写着自己名字的房子，逃出这个家
- 输入 110：一段报警对话，警察把妈妈带走，隐藏结局「正义の报警」
- 作者模式输入负数天数有彩蛋：穿越到妈妈还没出生的年代，触发祖父悖论

## 反转版玩法

规则全部反过来，考得好反而是坏事：

- 考砸（60 分以下）：妈妈反而放心，加血
- 考好（60 分及以上）：妈妈怕你太优秀，扣血，最高一次扣 10000
- 需要撑到 6570 天（18 岁）才到高考，中间每天都要考
- 最后一天高考，0-750 分，分数越高结局越惨：
  - 700 分以上：妈妈认定你作弊，被打死
  - 400-699 分：考上本科却被逼复读、关在家里，失去自由
  - 200-399 分：大专，妈妈懒得管，搬出去住，自由
  - 200 分以下：妈妈气晕没人管你，反而自由
- 输入 110：警察抓的是你自己
- 输入 跑：年龄越小越容易跑掉，快成年了反而在门口被抓回

## 两个版本对比

- 通过条件：原始版撑过 5 天，反转版撑到 6570 天
- 考砸：原始版扣血，反转版加血
- 考好：原始版加血，反转版扣血
- 110 报警：原始版抓妈妈，反转版抓你自己
