隐私政策

适用于《逃家游戏》网页版、桌面版、安卓版及其排行榜、投诉中心、举报中心与 Telegram 机器人。最近更新：2026-11-28

这款游戏是一个人做的免费文字游戏，不收集与你身份直接对应的信息，也没有广告和画像追踪。下面按你实际会碰到的情况逐条说明。

一、会记录哪些信息

  • 随机设备标识：首次打开时本地生成的一串随机字符，用来记住你的进度、金币和留言归属。它不对应你的姓名或手机号，清缓存后会重新生成。
  • 你主动填的内容：注册时的昵称（1–4 字）与密码（只保存加密哈希，明文不会存）、排行榜成绩、留言、举报理由、密码重置申请。
  • 访问记录：打开页面时记录 IP 地址、浏览器标识（User-Agent）、访问路径与时间。用途只有一个——判断访问是真人还是自动程序，防止刷榜和恶意请求。
  • Telegram 机器人：你私聊机器人时，会收到你的 Telegram 数字 ID 与消息内容，用于发激活码和回复提问。

二、存在哪里、谁能看到

数据存放在 Supabase（数据库）与 Cloudflare（机器人服务）的服务器上，网页本身托管在 GitHub Pages。除作者本人为处理举报、封禁、密码重置而查看外，不会提供给第三方，也不用于广告投放。

三、保留多久

  • 排行榜成绩：保留到你主动删除，或账号长期不用后清理。
  • 访问记录：仅用于短期风控，保留约 30 天后清理。
  • 留言与举报：处理完毕后保留记录以备复查，可应你要求删除。

四、你的权利

你可以要求查看、更正或删除与自己相关的记录：在游戏内用「删除我的成绩」自助下架，或在投诉中心留言说明需求；也可以直接在仓库提 Issue。

五、未成年人

游戏不含付费内容与广告。若你未满 14 周岁，请在监护人知情的情况下使用；如需删除相关记录，可由监护人代为联系。

六、联系方式

机器人：Telegram @taojia_group_bot

七、变更

若收集范围发生变化，会更新本页并在仓库 CHANGELOG 中注明。继续使用即视为接受更新后的说明。
